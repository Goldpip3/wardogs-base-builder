Weight, how much room a thing takes, how many go in a slot and what unlocks it are transcribed from the same item database as the prices, read on 2026-08-31. They are not measured in game: a bag is counted as squares, and the game packs shapes, so a bag with room left in it can still refuse a long item. A kit that carries something the database has no weight for says so with a plus on the total rather than quietly leaving it out. Anything somebody has since counted in game is marked on its card and used ahead of the database.
